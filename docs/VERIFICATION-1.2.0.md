# 1.2.0 验收记录

本轮在 Windows 64 位机器上完成，未访问或修改远端 GitHub 仓库。

## 实际验证

- Windows 主程序编译与独立启动、关闭。
- CPU、可用物理内存、系统内存提交额度读取。
- NVIDIA GeForce RTX 4080 Laptop GPU 和 AMD Radeon 610M 的占用和显存计数读取。
- 简体中文、英语、日语、韩语、德语、法语、西班牙语界面切换。
- 默认尺寸、最小尺寸截图检查，修复标题、资源条和下拉框的布局与绘制。
- 参数估算与系统余量比较：资源充足不提醒、内存不足提醒、提交额度耗尽提醒、指标过期不判断、CPU 满载不单独提醒。
- 预警返回设置时不启动转换、不创建输出。
- 真实无效输入引擎错误，仅通知一次，不触发成功求赞提示。
- 六种导出：SOG、标准 PLY、压缩 PLY、CSV、HTML、体素 ZIP。
- 多文件合并、单文件变换、点数精简分两步编码。
- 约 472 MB、200 万点模拟 PLY 转 SOG。
- 取消任务不替换已有输出，临时目录清理。
- 首次成功的求赞提示仍只记录一次。
- 10 项跨平台逻辑测试通过：参数限制、六种格式、一次性提示、七语言完整性、原始内存错误分类、预警资源策略、元数据估算等。
- macOS 网页界面源码通过浏览器自动交互：七语言、桌面/窄窗口、资源角标、图标、格式与操作切换、模拟转换和仓库入口。

## 未验证或不承诺

- 没有重新运行用户的 3490 万点真实场景，未宣称已解决引擎极大单个 SOG 的内存限制。
- 真实内存耗尽并未人为压垮系统重现；以用户实际错误文本测试诊断分类，并以独立资源快照测试风险策略。
- 没有重新构建苹果 1.2.0 应用，也没有 Mac 真机测试。macOS GPU 使用率/显存的不可用指标明确保留为未知。
- 估算区间不是精确峰值预测，驱动、后台程序、输入格式与筛选后的点数都会影响实际需求。
