# 国际化（i18n）架构与社区翻译贡献指南

Splat Convert Desktop 采用**代码与文案彻底解耦**的轻量零依赖国际化架构，以**简体中文（`zh-CN`）**作为单一事实来源（Single Source of Truth）与强制兜底语言，覆盖全部 3 个子系统：

- **Windows 原生主界面（C# WinForms）**：`windows/I18n.cs` + `windows/*.cs`
- **WebView2 3D 高斯编辑器（HTML + ES Modules）**：`windows/editor/i18n.js` + `windows/editor/domain/contracts.mjs` + `windows/editor/**`
- **macOS / Electron 壳层**：`app/i18n.cjs` + `app/*`

> 语言切换器仅保留在主界面（WinForms 右上角语言下拉框 / Electron 主界面），切换后零重启即时刷新主界面并通过 `setLanguage` 消息实时热同步至 3D 编辑器。

---

## 1. 目录结构与文件格式

所有语言包统一存放在根目录 [`locales/`](../locales/)，按 BCP-47 语言代码拆分独立 JSON 文件（UTF-8 无 BOM、2 空格缩进、Git Diff 友好）：

```text
locales/
├── zh-CN.json   # 基准语言（Source of Truth，包含 common.* / app.* / editor.* 全部 Key）
├── en-US.json   # English
├── ja-JP.json   # 日本語
├── ko-KR.json   # 한국어
├── de-DE.json   # Deutsch
├── fr-FR.json   # Français
└── es-ES.json   # Español
```

每个语言文件顶部包含 `_meta` 元数据块，其余为层级化的英文语义 Key：

```json
{
  "_meta": {
    "code": "en-US",
    "legacyCode": "en",
    "name": "English",
    "nativeName": "English",
    "order": 2
  },
  "common": { ... },
  "app": { ... },
  "editor": { ... }
}
```

## 2. 核心设计规范

1. **语义化分层 Key**：禁止使用中文原文作为 Key，统一采用小写驼峰/点分路径（如 `app.btn.startConvert`、`editor.menu.file`、`editor.measure.smartSnapBtn`）。
2. **变量插值（禁止字符串拼接）**：动态参数统一使用 `{var}` 占位符，例如：
   - `zh-CN.json`: `"已处理 {count} 个文件，耗时 {sec} 秒"`
   - `en-US.json`: `"Processed {count} files in {sec}s"`
   翻译时必须**原样保留所有 `{var}` 占位符名称**，允许按目标语言语序自由调整位置。
3. **严格兜底（Fallback）**：任意目标语言缺失某 Key 或值为空字符串时，运行时自动回退显示 `zh-CN` 文案，绝不在界面暴露原始 `a.b.c` Key。
4. **自动发现机制**：
   - 构建期：`windows/Build.ps1` 与 `scripts/build.cjs` 自动扫描 `locales/*.json` 打包，无需手工维护语言枚举。
   - 运行期（零编译热测）：Windows 便携版启动时会自动扫描程序同级 `data/locales/*.json`（及仓库根目录 `locales/*.json`），社区贡献者直接丢入新语言 JSON 即可立即在下拉框中选择并预览，无需安装编译器或重新构建！

## 3. 开发者新增 UI 文案标准流程

日常开发只需维护 `locales/zh-CN.json`：

1. 在 `locales/zh-CN.json` 对应模块（`common` / `app` / `editor`）下新增语义化 Key 与中文文案。
2. 在业务代码中调用对应翻译入口：
   - **C# WinForms**：`I18n.T("app.xxx.yyy")` 或 `I18n.Format("app.xxx.yyy", "count", n)`
   - **3D 编辑器 HTML**：`data-i18n="editor.xxx"` / `data-i18n-html` / `data-i18n-title` / `data-i18n-aria`
   - **3D 编辑器 JS**：`t("editor.xxx", { count })`（纯领域模块 `domain/*.mjs` 使用 `domainT(...)`）
   - **Electron**：`t("app.xxx", { count })`
3. 运行差异校验工具检查代码引用与多语言缺口：

```sh
# 扫描代码引用的全部 Key 并比对所有语言包覆盖率与占位符一致性
npm run i18n:check

# 严格模式（CI 用：有任意缺失/多余/空值/占位符不匹配即返回非 0）
node scripts/i18n-check.mjs --scan-code --strict

# 仅导出某个语言待翻译的增量缺口 JSON（便于直接交给 AI 或社区翻译）
node scripts/i18n-check.mjs --export-missing ja-JP --out missing-ja-JP.json
```

## 4. 社区新增一门语言 / 修正翻译（贡献者指南）

欢迎为 Splat Convert Desktop 贡献新语言（如 `zh-TW`、`pt-BR`、`ru-RU`、`it-IT` 等）或润色现有翻译：

1. **复制模板**：复制 `locales/zh-CN.json` 为 `locales/<BCP-47代码>.json`（例如 `locales/pt-BR.json`）。
2. **填写 `_meta`**：更新 `code`、`legacyCode`、`name`、`nativeName`、`order`（如 `order: 8`）。
3. **翻译文案并遵守以下约定**：
   - 保持 JSON 嵌套结构与 Key 名称 100% 一致；
   - 原样保留全部 `{var}` 占位符与 `<strong>...</strong>` 等 HTML 标签；
   - **勿翻译** CLI 参数、快捷键与专业缩写：`--stats`、`--filter-floaters`、`--decimate-adaptive`、`Ctrl+Z`、`W/E/R`、`SH`、`SOG`、`SPZ`、`PLY`、`HTML`、`PNG`、`WebGPU`、`WASM`、`LUT`、`HSL`、`RGB`、`HSV`、`+Y`、`Y=0`、`LaMa`、`SAM 2.1`、`L0`/`L1`/`L2`、`m/cm/mm`；
   - 保持左侧工具栏短标签（`editor.rail.*`）、调色滑块名（`editor.color.sliders.*`）与主界面按钮尽量简短，防止拉丁语系溢出截断。
4. **免编译实机预览**（可选）：把你的 `pt-BR.json` 放进便携版同级目录 `data/locales/pt-BR.json`，直接双击启动 `.exe`，在右上角语言下拉菜单切换即可实时检查主界面与 3D 编辑器排版！
5. **提交 PR 前运行校验**：

```sh
npm run i18n:check
```

确认输出中你的语言达到 `100.0% (0 missing, 0 empty, 0 extra, 0 placeholder mismatches)` 即可提交 Pull Request！
