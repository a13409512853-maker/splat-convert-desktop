# Windows V1.9 三维高斯编辑模块架构与操作参考

> 本模块为全自主研发的 **右手 `+Y` 朝上** 非破坏性 3D 高斯泼溅编辑器（`windows/editor/`），经 `editor.manifest.json` 内容哈希隔离解包并在 WebView2 虚拟主机离线运行；同时在 `windows/native-viewport/` 提供可选的 C++20 / Vulkan 1.3 实验性旁路视口。

---

## 2. 模块目录与数据流契约

- **`windows/EditorHost.cs`**：`SceneEditorDialog` 负责 Manifest 指纹隔离解包（`data/runtime/editor-<ver>-<hash>`）、WebView2 虚拟主机映射、1Hz 硬件遥测推送、本地模型管理与非破坏性配方往返；源文件严格只读。
- **`windows/editor/domain/*.mjs`**：零 DOM / 零 WebGL 纯领域层（`EditSession` 单写者、`SceneStateStore`、`recipe-codec.mjs`、`box-select-tool.mjs`、`contracts.mjs`），兼容 `v1–v4` 配方与历史 `z-up` 坐标/圆柱迁移。
- **`windows/editor/cloud.js` + `shaders/splat-shaders.js` + `sort-worker.js`**：WebGL2 实例化 3D 高斯渲染器（100% 全量点无降采样、Splat/Centers/Rings 三模式、32-bit GPU ID 拾取、脏行稀疏纹理上传、实时 GPU 包裹体范围染色、堆体 4 视图与专业调色着色器）。
- **`windows/editor/csg.js` + `volumes.js`**：GLSL3 解析光线投射 RPN CSG 组合包裹体引擎（盒/球/圆柱递归嵌套、零剪切 6 面控点与射线遮挡减淡）。
- **`windows/editor/semantic/` + `smart/` + `measure/`**：离线 `SAM 2.1 Tiny` 2D/3D 语义分割、平面补洞 L0/L1/L2 与 3DGS 智能测量与 2.5D 堆体积分。
- **`windows/editor/ply-parallel.mjs` + `ply-chunk-worker.mjs` + `ply.mjs`**：64 MiB 严格在途缓冲上限的多核流式无损 PLY 烘焙器（只读 `SharedArrayBuffer` 位图 + 原子 `.tmp` 落盘），与串行金标 100% SHA-256 比特一致。
- **`windows/native-viewport/` + `windows/NativeViewportDialog.cs`**：实验性 C++20 / Vulkan 1.3 旁路渲染引擎（默认关闭，通过右键「3D 编辑」、`Shift+左键` 或 `--native-viewport` 启动）。
